# Car Rental Price Calculator

A beginner-friendly Python project that calculates the total rental cost of a car based on the number of days rented and the distance traveled.

## Features

* Accepts the number of kilometers driven
* Accepts the number of rental days
* Calculates the total rental cost
* Displays the result in a user-friendly format

## Pricing Rules

* R$60.00 per rental day
* R$0.15 per kilometer driven

## Technologies Used

* Python 3

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/car-rental-price-calculator.git
```

2. Navigate to the project folder:

```bash
cd car-rental-price-calculator
```

3. Run the script:

```bash
python main.py
```

## Example

Input:

```text
How many kilometers were driven? 300
For how many days was the car rented? 5
```

Output:

```text
Considering that you drove 300.0 km during a period of 5 days, the amount to pay is R$345.00
```
